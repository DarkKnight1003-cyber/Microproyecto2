\# Microproyecto 2 - Computación en la Nube



Despliegue de un clúster de Azure Kubernetes Service (AKS) con aplicaciones de ejemplo, como parte del curso de Computación en la Nube de la Especialización en IA (UAO).



\## Estructura



\- 01-cluster-aks: scripts y notas de creación/destrucción del clúster

\- 02-image-classifier: aplicación de clasificación de imágenes

\- 03-app-propia: aplicación de elección propia

\- 04-monitoreo: evidencias de supervisión y monitoreo en AKS
